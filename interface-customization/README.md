# NightShift Interface Customization

Adds an `Aa` button beside Settings in the NightShift header. The button toggles a compact layout with shorter browser bars, a narrower sidebar, and less padding on internal pages. The choice is saved in local storage on the current device. Press the button again to restore the comfortable spacing.

The plugin's **Settings** panel at `nightshift://plugins` also offers four color themes: Night Lime (default), Ocean, Violet, and Ember. A selection applies immediately and is saved with NightShift's plugin settings in this browser.

The layout toggle is additive and leaves the address field, navigation buttons, tabs, and Settings control in place. Manage or disable the plugin at `nightshift://plugins`. Theme changes apply immediately; the compact layout preference applies after reload.
